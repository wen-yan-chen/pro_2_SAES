# S-AES 综合加解密工具 - 用户指南

## 1. 项目简介
本项目基于《密码编码学与网络安全》附录D中的简化AES（S-AES）算法标准开发。软件采用图形化用户界面（GUI），支持单次加解密、ASCII字符串处理、双重/三重加密（包含中间相遇攻击验证）以及密码分组链（CBC）工作模式。本指南旨在帮助用户快速了解软件功能并进行交互操作。

## 2. 运行环境
- **编程语言**：Python 3.x
- **依赖库**：仅使用 Python 标准库（`tkinter`），无需安装第三方依赖包。
- **操作系统**：Windows / macOS / Linux 均可正常运行。

## 3. 启动方式
1. 在 PyCharm 中打开本项目。
2. 在左侧项目目录中，依次展开 `gui` 文件夹，找到并双击打开 `app.py`。
3. 在代码编辑区右键，选择 **Run 'app'**（或点击右上角绿色的运行按钮）。
4. 稍等片刻，系统将自动弹出图形化操作界面。

## 4. 界面功能说明

程序主界面采用选项卡（Tab）设计，包含三个独立的功能模块：

### 4.1 选项卡一：第1/3关 - 基础加解密
- **密钥输入**：必须输入 16-bit 的十六进制数据（4个字符，例如 `4AF5`）。
- **输入数据**：
  - **16-bit 模式**：输入 4 个十六进制字符（例如 `D728`），将作为单个分组进行加解密。
  - **ASCII 模式**：输入任意长度的英文字符串（例如 `HELLO`）。程序会自动按 2 字节（16-bit）为一组进行切分加密。
- **操作**：点击“单次加密”或“单次解密”按钮，结果将直接显示在下方输出框中。

### 4.2 选项卡二：第4关 - 多重加密
- **双重加密**：在密钥框输入 32-bit 密钥（8个字符，例如 `4AF51234`，即 K1+K2）。输入 4 字符的 16-bit 明文，点击“双重加密/解密”。
- **三重加密**：在密钥框输入 48-bit 密钥（12个字符，例如 `4AF51234ABCD`，即 K1+K2+K3）。点击“三重加密/解密”。
- **中间相遇攻击演示**：
  - 在输入框填入明文，并在密钥框填入双重加密的 32-bit 密钥。
  - 点击“运行中间相遇攻击”，程序会遍历所有可能的密钥对，破解出 K1 和 K2 候选值，并显示运算耗时。

### 4.3 选项卡三：第5关 - CBC 工作模式
- **密钥**：16-bit 十六进制密钥（4个字符）。
- **IV（初始向量）**：16-bit 十六进制数（4个字符，默认 `0000`），加密方和解密方必须使用相同的 IV。
- **输入**：支持长字符串。
- **操作**：
  - 点击“CBC 加密”，输出框会生成以空格分隔的 16-bit 十六进制密文块。
  - 点击“CBC 解密”，将密文块原样粘贴回输入框，即可还原明文。
  - **篡改测试**：加密后，手动修改密文块中的某一字符，再次点击解密，可观察到被篡改块及其后续所有块都会变成乱码。

## 5. 输入格式与注意事项
1. **十六进制格式**：输入数字和 A-F 即可，无需输入 `0x` 前缀，大小写均支持。
2. **长度校验**：若密钥或数据长度不符合要求，系统会自动弹出错误警告框，请根据提示检查字符数量。
3. **ASCII解密**：若解密还原出不可见字符（如补齐用的空字符 `\x00`），程序会自动将其过滤，保证界面显示正常。
