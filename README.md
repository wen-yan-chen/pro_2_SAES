🛡️ S-AES 综合加解密工具 (pro_2_SAES)
《信息安全导论》课程作业—— 基于《密码编码学与网络安全（第 8 版）》附录 D 标准开发。

本项目实现了一个功能完备的简化 AES（S-AES）加解密工具，采用图形化用户界面（GUI）。不仅支持基本的单次加解密，还深入实现了 ASCII 字符串分组处理、双重/三重加密、中间相遇攻击（MITM）以及密码分组链（CBC）工作模式与错误传播分析。

📂 项目结构
采用算法层与界面层解耦的架构设计，确保核心算法可作为纯函数被独立调用：

pro_2_SAES/
├─ gui/                  # GUI 层：tkinter 界面 + 交互逻辑
├─ saes/                 # 算法层（独立纯函数，无界面依赖）
│   ├─ core.py           # 核心算法：S盒、密钥扩展、单分组加解密
│   ├─ multi_crypto.py   # 多重加密：双重、三重、中间相遇攻击
│   └─ cbc_mode.py       # 工作模式：CBC 加解密
├─ tests/                # 测试脚本
│   └─ test_core.py      # 标准向量自测
└─ docs/                 # 相关文档与测试截图

🚀 快速开始
本项目仅依赖 Python 标准库（tkinter），无需安装任何第三方包。
运行环境： Python 3.8+（实测 3.13）

1. 启动图形界面
python gui/app.py

3. 运行单元测试（教材标准向量自测）
python tests/test_core.py
